# 📱Тестирование мобильного приложения

В рамках проекта выполнено: </br>
&nbsp;&nbsp;• функциональное тестирование;</br>
&nbsp;&nbsp;• позитивное и негативное тестирование;</br>
&nbsp;&nbsp;• тестирование валидации;</br>
&nbsp;&nbsp;• тестирование поведения приложения при входящем вызове (incoming call);</br>
&nbsp;&nbsp;• тестирование изменения ориентации экрана и адаптивности UI;</br>
&nbsp;&nbsp;• тестирование жизненного цикла приложения;</br>
&nbsp;&nbsp;• тестирование совместимости.</br>

Для тестирования было использовано реальное устройство и эмулятор "Android Studio".</br>
